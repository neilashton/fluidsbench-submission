# DrivAerML

The active specification is still a closed prototype with generated dummy case
IDs. It must not be used for real submissions.

The dataset-owner review package for replacing that prototype is in
[`proposal/`](proposal/). It pins the public dataset and split identities,
separates canonical finite-volume scoring from AB-UPT and GeoTransolver
paper-parity scoring, and lists the remaining approval blockers. Nothing in the
proposal directory opens submissions or changes historical results.
